| `SAT-MATH-S04-T01` | Ratio — Year 6 | Use ratio language and notation to compare quantities. | None present. | A two-row exact unit diagram: 2 equal blue counters to 3 equal gold counters, labelled `2:3`, with a second scaled row of 4 to 6. | Every counter must have equal size; the two rows must preserve the same ratio; do not imply addition instead of multiplicative scaling. |
| `SAT-MATH-S04-T02` | Proportion and comparison — Year 6 | Reason about multiplicative relationships and comparisons. | None present. | A paired double-number-line or proportion table using a fixed unit rate, with corresponding values vertically aligned. | Both scales need consistent spacing; zero and matched pairs must align; labels and units must not mix additive and multiplicative comparisons. |

| `SAT-MATH-S04-T05` | Function machines — Year 6 | Follow and reverse one-step and two-step number rules. | None present. | A labelled two-step function machine with an input, `+ 7`, then `× 2`, and a reverse path using the true inverse operations. | Operation order is essential; reverse arrows must use `÷ 2` then `− 7`; each displayed input/output pair must calculate exactly. |
| `SAT-MATH-S04-T06` | Missing numbers, equations and substitution — Year 6 | Find missing values and solve suitable one-step equations. | None present. | A balanced equation strip for `n + 7 = 15`, followed by substitution `8 + 7 = 15`. | Both sides of the equals sign must remain equal; the unknown must be used consistently; avoid implying that an equation is a left-to-right instruction. |
| `SAT-MATH-S04-T07` | Linear number sequences — Year 6 | Continue sequences and describe the rule. | None present. | Equally spaced sequence tiles `4, 7, 10, 13, …` with repeated `+3` arrows and a separate rule label. | Physical positions must not suggest unequal numeric intervals; the stated rule and every successive difference must agree; do not confuse term position with term value. |
| `SAT-MATH-S04-T08` | Number puzzles — Year 6 | Use number relationships to solve structured challenges. | None present. | A compact constraint-puzzle board using a clearly stated, uniquely solvable arithmetic condition, then a short checked solution. | The puzzle must genuinely have one solution; every condition must be visible; notation, operation priority and the checking line must all agree. |
